# Lab Rules

> 以下為 HRC 實驗室所有成員必須共同遵守之規定。  
> 進入實驗室或使用實驗室資源前，請務必詳閱並確實遵守。


## 1. 入室與離室

1. 進入實驗室室內區域前，請**脫鞋**，並將鞋子整齊放置於鞋櫃。
2. 若實驗室內已無其他成員，離開前請確實**鎖門、關燈並關閉冷氣**。

---

## 2. 環境整潔與安全

3. 室內可飲食，但廚餘與餐飲包裝請自行帶至室外丟棄，**勿留置室內**以免孳生昆蟲。
4. 實驗室內**嚴禁用火**，並嚴禁攜入或使用爆裂物。
5. 請依照**輪班表**執行倒垃圾、使用吸塵器掃地及其他基本清潔工作。

---

## 3. 設備與資源使用

6. 鋰電池充電前，務必**填寫充電表單**，並閱讀與遵守鋰電池充電須知。
7. 實驗室所有產物、設備、工具、零件、線材、耗材與文件，**未經允許不得外借**。

---

## 4. 實驗與學術規範

8. 使用機器人進行任何實驗前，請務必確認**周遭環境安全**，並確認**電池狀態正常且健康**。
9. 口試與預口試皆須提供口試委員**論文相似度比對**報告；扣除 reference 後，相似度須在 **10% 以下**。
